# wonmook-hs

원묵고등학교 홍보 웹페이지 (2026학년도)

> 꿈과 이상을 실현하는 공교육의 새로운 모델

2026 중랑구청 학교홍보자료와 학교 사진, 60초 홍보영상을 바탕으로 만든 한 페이지짜리 학교 소개 사이트입니다. 빌드 과정 없이 정적 파일만으로 동작합니다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 페이지 전체 (HTML·CSS·JS 한 파일) |
| `img/` | 학교 사진, 공식 로고(원형·가로형), 영상 포스터 |
| `media/promo.mp4` | 60초 홍보영상 (720p, 약 4MB) |

## 섹션

학교 소개(교훈·교표) → 숫자로 보는 원묵 → Choose(학년별 교육과정) → Create(창의·탐구) → 향학당 → Lead(진로진학·학교문화) → 캠퍼스 → 교육 성과 → 연혁 → 홍보영상 → 오시는 길

## 미리보기 / 배포

- 로컬: `index.html`을 브라우저로 열기
- GitHub Pages: 저장소 **Settings → Pages → Branch: `main` / `(root)`** 로 설정하면 `https://kkhland.github.io/wonmook-hs/` 에서 볼 수 있습니다.

## 내용 수정

- 교육과정 과목: `index.html`의 `const G={...}`
- 만족도 그래프: `const SAT=[...]`
- 향학당 운영 시간(평일 시작 16시로 가정): `tickClock()` 함수
